# Ionic Card Content

Source: https://ionicframework.com/docs/api/card-content

Sections: Properties · Events · Methods · CSS Shadow Parts · CSS Custom Properties · Slots

Card content is a child component of card that adds padding around its contents. It is recommended that any text content for a card should be placed inside of card content.

See the [Card](https://ionicframework.com/docs/api/card) documentation for more information.
