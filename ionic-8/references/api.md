# Ionic Framework API

Source: https://ionicframework.com/docs/api

Each Ionic [component](https://ionicframework.com/docs/components) consists of one or more [custom elements](https://developer.mozilla.org/en-US/docs/Web/Web_Components/Using_custom_elements). Each custom element, in turn, may expose properties, methods, events, and CSS custom properties.
